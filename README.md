# jacepark-lab

つくったものを、つくり方ごと公開する実験室です。

実際に運用しているものを **ゼロから組み直しながら記録** しています。
動画で手を動かし、記事で背景を書き、コードはここに置きます。

- ブログ — [jacepark.com](https://www.jacepark.com)
- 動画 — [YouTube @jaceparklab](https://www.youtube.com/@jaceparklab)

---

## 方針

**動くものだけを置きます。** 各フォルダは単体で実行できます。
全体をクローンして環境を組まないと動かない、という形にはしません。

**うまくいかなかったところも残します。** エラーで止まった箇所、
遠回りした手順、後から直した設計。そこが一番役に立つからです。

**本番のコードそのものではありません。** 運用中のものには鍵や個人情報が
入っています。ここに置くのは、同じ仕組みを最小構成で組み直したものです。
