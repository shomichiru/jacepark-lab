# 01 — まとめページを自動生成する

記事が増えるほど、まとめページの管理が破綻します。
記事を直したのに、まとめの方を直し忘れる。これが必ず起きます。

**まとめページを手で書くのをやめました。** 記事が自分の所属を宣言し、
スクリプトがそれを集めて一覧を作ります。

- 記事 — （公開後にリンク）
- 動画 — （公開後にリンク）

---

## 動かす

集計だけ表示する:

    python3 build_index.py posts

生成する:

    python3 build_index.py posts --build

`output/` に一覧の HTML が出ます。

---

## 仕組み

記事の先頭にメタブロックを置きます。

    <!--META
    title: ffmpeg で動画を切り出す
    slug: ffmpeg-trim
    tags: [ffmpeg, automation]
    note: 開始と長さを指定するだけ
    -->

`tags` に書いたものが、そのままページになります。
**3 件以上集まったタグだけ** ページを作ります。1~2 件で作ると、
中身の薄いページが並ぶだけになるからです。

同梱のサンプル 5 記事で動かすと、こうなります。

    ○ automation        3 件
    － ffmpeg            2 件
    － python            2 件

`automation` だけが生成対象です。

---

## ここは割り切っています

- **タグ名がそのままファイル名になります。** 日本語タグを入れると
  日本語ファイル名になります。運用では英数字のスラッグにして、
  表示名を別で持つ形にしました
- **出力は HTML の断片です。** そのまま公開できる形ではありません。
  実際の運用では CMS の投稿本文として使っています
- **同じ記事が複数のタグに入ります。** これは意図した動作です

---

## 動作環境

- Python 3.12（標準ライブラリのみ。インストール不要）
- macOS で確認

---

## 実際の運用では

この形を、韓国ドラマ・映画の紹介サイトで使っています。
「怖い」「泣ける」「あの世が出てくる」といった軸で、記事を横断して
まとめる用途です。記事を書くときにタグを 1 行足すだけで、
まとめページが勝手に増えます。
